01

What is Prefrontal?

```

Prefrontal gives you one interface for AI models running locally and in the cloud.

Instead of using a different application for every AI backend, Prefrontal acts as a unified control layer. Connect Ollama, llama.cpp, or OpenRouter and switch between them from the same frontend.

```
